# ESP32 Pin Mapping

## I2C Bus

GPIO 21 → SDA
GPIO 22 → SCL

Shared by:
- OLED Display 1
- OLED Display 2
- MPR121

---

# MPR121

GPIO 4 → IRQ

---

# DIP Switch Mapping

GPIO 13 → Switch 1
GPIO 12 → Switch 2
GPIO 14 → Switch 3
GPIO 27 → Switch 4
GPIO 26 → Switch 5
GPIO 25 → Switch 6
GPIO 33 → Switch 7
GPIO 32 → Switch 8

# Future Expansion Pins

# Reserved Pins

GPIO 1 → Serial TX
GPIO 3 → Serial RX

Reserved for debugging and firmware upload.
