# Modular Dual-Display Cyber-Console

A modular cyberpunk-inspired dual-screen handheld console combining AI interfaces, retro gaming systems, hardware utilities, and touch-based interaction into a portable cyber-console.

## Features

- Dual display architecture
- AI dashboard interface
- Retro mini-games
- Coding terminal
- Wi-Fi utilities
- MPR121 touch matrix controls
- DIP switch mode selection

## Hardware

- ESP32
- Dual OLED displays
- MPR121 touch controller
- DIP switch selector
- Battery-powered system

## Status

Currently under active development.
